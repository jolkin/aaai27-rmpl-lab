# AAAI-27 lab website: Programming Paradigms for Building Cognitive Agents

Supplemental website for the AAAI-27 RMPL lab. The lab materials themselves are at
https://gitlab.com/mit-mers/enterprise/rmpl-lab-2026.

- `site.html` — the page source. Edit this.
- `build.sh` — wraps it into `public/index.html`. Run it and commit both files.
- `.gitlab-ci.yml` — GitLab Pages serves `public/` from the default branch.
